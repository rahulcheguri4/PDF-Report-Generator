# 📄 Automated PDF Report Generator

A simple Python project that automatically generates a PDF business sales report from sample sales data.

# 📌 Project Description
# The PDF Report Generator processes business sales information and creates a structured PDF report containing:
Total number of products
Total quantity sold
Total sales
Sales details in table format

This project demonstrates how Python can be used for automated report generation and business data processing.

# 🎯 Objective:
•Learn Python automation
•Generate PDF reports programmatically
•Process business data
•Calculate summary metrics
•Create reusable reporting scripts

# 🛠️ Technologies Used:
•Python
•File Handling
•Data Processing
•PDF Generation
